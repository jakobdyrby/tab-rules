    A few things to know

    Domain matches an exact hostname and its subdomains: github.com.

    Wildcard matches the full URL, with * for any text: https://github.com/your-org/*.

    Regex uses a JavaScript regular expression, without surrounding slashes or flags: ^https://dev\.azure\.com/. Matching is case-sensitive; keep expressions simple.

    Groups are reused by exact name within the same window. Colour is set when a group is created. Apply to open tabs and the popup’s Apply rules or Regroup all tabs also refresh existing named groups to the saved rule colours, even with group protection on. Pinned, incognito, and non-web tabs are skipped. With “Respect existing groups” off, web tabs that stop matching any rule leave their group.

    With “Respect existing groups” enabled, URLs opened in any group stay there, even if another rule matches. Only ungrouped tabs are automatically grouped. Manually ungrouped tabs stay ungrouped for the browser session. Turn this option off to let rules reorganize grouped tabs too.

    “Keep groups in rule order” moves groups named in enabled rules to the front of each window, after pinned tabs. Other tabs and groups retain their relative order. This works with “Respect existing groups”: membership stays protected, but group positions follow the rules. Saving applies group order immediately while automatic grouping is enabled.

    Saving affects future tab activity. “Apply to open tabs” saves your edits and checks every open window, respecting the settings above. Nothing leaves your browser.
