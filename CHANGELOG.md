# Changelog

## Unreleased

- Add a toolbar popup with Apply rules, Order groups, Regroup all tabs, and Open settings.
- Allow manual grouping while automatic grouping is paused, without changing saved preferences.

## 0.1.0 beta — 2026-09-25

Initial public beta.

- Automatic grouping with domain, wildcard, and regex filters.
- Multiple alternative filters per rule and first-match priority.
- Existing-group protection and optional ungrouping when no rule matches.
- Optional group ordering after pinned tabs, per window.
- Rule actions menu, URL tester, match highlights, and local autocomplete.
- JSON import/export, extension icons, and responsive settings page.
- Public repository layout, CI, privacy documentation, and installable ZIP packaging.

Known limitations and manual validation are documented in `docs/behaviour.md` and `docs/testing.md`.
